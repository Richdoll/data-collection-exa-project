# Data Collection Exam Project

Web scraping (Selenium & No-Code Web Scraper), SQLite storage, and Streamlit dashboard application for **Books to Scrape** and **Gaaraas Dakar Auto**.

## Structure
- `app.py`: Main Streamlit multi-page application
- `database.py`: SQLite database initialization and helper functions
- `scraper_books.py`: Selenium scraper & cleaner for Books to Scrape
- `scraper_gaaraas.py`: Selenium scraper & cleaner for Gaaraas Auto
- `data/`: Stores raw CSVs from Chrome Web Scraper extension and `app_database.db`
